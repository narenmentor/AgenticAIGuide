What is Agentic AI?

A normal chatbot answers once. An AI agent is given a goal and keeps working until the goal is done.

Chatbot (reactive)

You ask, it replies. It cannot check a website, send an email or fix its own mistakes unless you do the next step.

AI agent (goal-driven)

You say "Find 5 competitors and email me a summary." It plans the steps, searches, reads, writes, sends, and checks the result.

One-line definition: Agentic AI = an LLM (the brain) + tools (the hands) + memory (the notebook) + a loop (think, act, observe, repeat).

Why do we need Agentic AI?

Real work has many steps, many apps and many surprises. One prompt cannot cover that.

Multi-step work

Research, write, check, format and send is a chain. Agents handle the chain end to end.

Fresh, real data

LLMs have a knowledge cutoff. Agents call search, databases and APIs for current facts.

Action, not just text

Agents can create tickets, update sheets, book slots and run code.

Self-correction

If a step fails, an agent reads the error and tries another way.

Time and cost savings

Repetitive tasks run in the background so people focus on judgement and creativity.

24/7 availability

Support, monitoring and follow-ups continue outside working hours.

Essential concepts for beginners

Learn these eight words and most agent tutorials will make sense.

LLM

The language model that reasons and writes (Llama, Gemini, GPT, Claude).

Prompt / system prompt

Instructions that define the agent's role, rules and tone.

Tools

Functions the agent may call: web search, calculator, email, database, code runner.

Tool / function calling

The model replies with "call this tool with these inputs". Your code runs it and returns the result.

Memory

Short-term: the current conversation. Long-term: saved notes or a vector database.

Planning

Breaking a goal into smaller steps and choosing the next one.

RAG

Retrieval-Augmented Generation: fetch relevant documents first, then answer from them.

Multi-agent

Several specialist agents (researcher, writer, reviewer) working together.

Common agent patterns

ReAct reason, act, observe in a loop   Plan-and-execute make a full plan, then run it   Reflection the agent critiques and improves its own output   Human-in-the-loop a person approves risky steps

Mini example: "Plan my learning week"

  1. Goal: "Prepare me for a Python interview in 7 days."
  2. Agent plans: topics, daily time, practice questions.
  3. Calls tools: calendar (find free slots), search (top questions), notes (save the plan).
  4. Observes: Wednesday is busy, so it moves the session to Thursday.
  5. Delivers the final schedule and sends a reminder.

Build a basic agent with code (free)

We use Ollama to run a free model locally. No credit card and no API key are needed. Free hosted tiers such as Google AI Studio or Groq also work if your laptop is slow, but their limits and model names change, so check their current pages.

  1. Install Ollama from ollama.com, then run ollama pull llama3.1 (any model that supports tools works).
  2. Install Python 3.10+ and run pip install ollama.
  3. Save the code below as agent.py and run python agent.py.
import ollama
from datetime import datetime

# ---- 1. TOOLS: plain Python functions the agent may call ----
def calculator(expression: str) -> str:
    """Calculate a math expression such as 12*(3+4)."""
    if not all(c in "0123456789+-*/(). " for c in expression):
        return "Error: only numbers and + - * / ( ) allowed"
    return str(eval(expression))   # demo only; fine because input is filtered

def get_time() -> str:
    """Return the current date and time."""
    return datetime.now().strftime("%d %b %Y, %H:%M")

TOOLS = {"calculator": calculator, "get_time": get_time}

# ---- 2. THE AGENT LOOP: think, act, observe ----
def run_agent(goal: str, max_steps: int = 5):
    messages = [
        {"role": "system", "content": "You are a helpful agent. Use tools when needed."},
        {"role": "user", "content": goal},
    ]
    for step in range(max_steps):
        reply = ollama.chat(model="llama3.1", messages=messages,
                            tools=[calculator, get_time]).message
        messages.append(reply)

        if not reply.tool_calls:          # no tool needed, so we have the answer
            return reply.content

        for call in reply.tool_calls:     # run each requested tool
            name = call.function.name
            result = TOOLS[name](**call.function.arguments)
            print(f"[step {step+1}] {name} -> {result}")
            messages.append({"role": "tool", "tool_name": name,
                             "content": str(result)})
    return "Stopped: step limit reached."

print(run_agent("What is today's date, and what is 18% of 2450?"))

What to notice

  • The docstrings tell the model what each tool does, so write them clearly.
  • The for loop is the agent's think, act, observe cycle.
  • max_steps prevents endless loops.
  • Next upgrades: add a web-search tool, save messages to a file for memory, then move to LangGraph or CrewAI.

Build a basic agent with no code (free)

Example: an agent that reads a question, searches the web and replies. We use n8n (free self-hosted community edition; the cloud version has a trial) or Flowise (free, open source).

Option A: n8n

  1. Open n8n and create a new workflow.
  2. Add a Chat Trigger node.
  3. Add an AI Agent node and connect it.
  4. Under Chat Model, choose Ollama (local, free) or Google Gemini with a free API key from AI Studio.
  5. Under Memory, add Window Buffer Memory.
  6. Under Tools, add Calculator, Wikipedia or an HTTP Request tool.
  7. Write the system message: "You are a helpful research assistant."
  8. Click Chat and test.

Option B: Flowise

  1. Install with npx flowise start (needs Node.js).
  2. Create a new Agentflow or Chatflow.
  3. Drag in a Chat Model (Ollama or Gemini).
  4. Add a Tool Agent, then attach Calculator and a search tool.
  5. Add Buffer Memory.
  6. Press the chat icon to test, and use Embed to put it on a website.

Good habits and safety

Limit permissions

Give the agent only the tools it truly needs. Prefer read-only access first.

Human approval

Ask for confirmation before sending emails, spending money or deleting data.

Check the output

Agents can be wrong and sound confident. Verify important facts.

Protect secrets

Never paste API keys into code you share. Use environment variables.

Beware prompt injection

Web pages or emails can contain hidden instructions. Treat tool output as data, not commands.

Log and limit

Record every step and set step and cost limits.

Your beginner learning path

  1. Learn Python basics: functions, JSON, APIs.
  2. Practise prompting: roles, examples, output formats.
  3. Build the single-tool agent above, then add 2 or 3 more tools.
  4. Try a no-code agent in n8n or Flowise for a real task of your own.
  5. Add memory and RAG over a few PDFs.
  6. Learn LangGraph or CrewAI and build a two-agent team (researcher and writer).
  7. Publish a small project on GitHub and share what you learned.
